# 置信度怎么给

不要一律给 0.9。按下面的档位来，`confidence` 会直接决定这条变更排在哪里。

| 区间 | 含义 | 典型情形 |
|:--|:--|:--|
| 0.85–1.0 | 改动明确、条款号清楚、影响可直接判断 | 限值从 700 改成 720，条款号齐全 |
| 0.65–0.85 | 改动清楚，但影响需要一层推断 | 试验方法变了，要不要重做 DVP 需判断 |
| 0.45–0.65 | 文本残缺、条款号缺失、或语义模糊 | PDF 抽出来的段落断句错乱 |
| 0.0–0.45 | 基本靠猜 | 差异只有孤立词组，看不出上下文 |

## 几条纪律

- 差异文本碎片化、只有半句话 → 最高给 0.6
- `criteria` 里超过一半条目给不出条款号 → 最高给 0.5
- 变更类型是「勘误」而你无法确定改了什么 → 给 0.4，并在 `summary` 里写明"疑似勘误，请人工确认"
- 涉及**过渡期、豁免到期、强制实施日**的改动，`confidence` 不因文本残缺而降低——
  这类时间信息本身就是结论，残缺也要报出来
