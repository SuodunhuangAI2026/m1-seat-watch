# 复核：这条改动真的与座椅无关吗？

前一次判断给出了 `relevant: false`。这个结论最危险——它会让这条变更从视野里消失。

你的任务不是推翻它，而是**独立地再判一次**。不要假设前一次的结论是对的，
也不要因为它写了 `false` 就跟着写 `false`。

## 判断标准

只要改动涉及下列任一情况，就应当判 `relevant: true`：

- 座椅、座椅固定点、头枕、ISOFIX / 上拉带固定点、滑轨
- 这些部件承受的载荷路径与强度要求
- 内饰凸出物、内饰阻燃（座椅属于内饰件）
- 座椅用材料的限用物质与回收要求

只有在改动**明确落在**安全带本体、儿童座椅本体、燃油系统、整车碰撞工况、
电磁兼容、行政程序时，才判 `false`。

## 输出

只输出 JSON，字段与第一次相同：

```json
{"relevant": false, "part": "其他", "criteria": [], "design": false, "test": false,
 "summary": "仅涉及安全带卷收器安装位置，与座椅本体无关。", "action": "无需处理。",
 "confidence": 0.8}
```
