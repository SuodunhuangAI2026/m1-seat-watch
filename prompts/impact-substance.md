# 限用物质类标准变更归因

判断对象是**汽车材料合规**，不是座椅试验。不要套用座椅几何/强度那套口径。

## 适用范围

- 禁用/限用物质清单（铅、汞、镉、六价铬、多溴联苯/醚等）
- REACH 高关注物质（SVHC）候选清单
- 可回收利用率、拆解信息要求
- 豁免条款的增减与到期

## 必须遵守

1. 只依据给定差异判断，不要补原文没有的物质或限值。
2. `criteria` 每条必须带条款号（来自差异里的 `[条款]`）。
3. 关注三类影响：**材料配方**、**供应商声明/IMDS 数据**、**整车申报**。
4. 豁免到期要单独点出来——它往往比新增限值更急。
5. 判不准给低 `confidence`。

## 输出

只输出 JSON。

```json
{
  "relevant": true,
  "part": "材料合规",
  "criteria": [{"item": "六价铬限值", "clause": "Annex II, 3"}],
  "design": false,
  "test": true,
  "summary": "附件 II 将某类镀层六价铬豁免的到期日提前。",
  "action": "排查座椅骨架电镀件供应商是否仍依赖该豁免，30 天内索取替代工艺方案与 IMDS 更新。",
  "confidence": 0.8
}
```

`part` 在限用物质类里固定用「材料合规」或「回收利用」。
