"""人工上传目录。

没有公开正文源的标准（T2：付费/登录/扫描件；T3：根本没有官方公开版），
把文本放到这里，系统照常比对、归因、出报告。

## 怎么放

```
data/manual/
├── QC-T-740-2017/
│   ├── QC/T 740-2017.txt      ← 旧版
│   └── QC/T 740-2024.txt      ← 新版（文件名就是版本号）
├── GSO-1598-2002/
└── T-CAAMTB-284-2025/
```

- 一个版本一个 `.txt`，**文件名即版本号**，会和报告里的「版本变化」对上
- 中文用 UTF-8 保存
- 按文件修改时间取最新的一份去比对；放进来第二天就会出变更
- 从 PDF 里复制文本时，尽量保留条款号（`5.2.3` 这种开头），比对才准

## 为什么不做 OCR

扫描件识别错的代价比漏识别高得多——一条错的条款会直接进 DVP。
所以宁可让你手工贴一次，也不让系统猜。
